# Contributing to SmartGurd Pro

Thank you for contributing to SmartGurd Pro! This document explains how to get started and submit improvements.

## Development Setup

1. Install Flutter SDK and platform tooling.
2. Run:

```bash
flutter pub get
```

3. Run the app locally:

```bash
flutter run
```

## Branching & Commits

- Create feature branches from `main`.
- Use descriptive commit messages.
- Keep changes limited to a single concern per commit.

## Pull Requests

- Describe the change clearly.
- Include screenshots for UI updates.
- Add tests for new functionality when possible.
